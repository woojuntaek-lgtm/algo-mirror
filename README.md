# 알고리즘 거울

숫자 뒤에 숨은 세상 3편 「추천 알고리즘과 데이터의 착시」의 부록 앱입니다. 내 구매 칸을 바꾸며 닮은 사람들로 빈칸을 확률로 채우는 협업 필터링, "정말 듣고 있을까"에 대한 사실 정리, 피드를 누를 때마다 내 점이 움직이며 거품이 생기는 취향 지도(임베딩·필터 버블 모의 실험)와 "거품에 구멍 내기", 평균과 중앙값의 함정, 누구에게 물었나(사이트 투표·내 피드·고르게 뽑은 표본), 숫자 앞에서 세 가지 질문 퀴즈와 세 가지 습관을 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 알림
- 사람·구매 기록, 콘텐츠 지도, 마을 1만 명의 의견은 모두 앱이 만든 예시·모의 실험 자료입니다.
- 협업 필터링은 코사인 유사도와 가중 평균으로 계산합니다. 취향 지도는 수백 개의 축을 두 축으로 줄인 그림입니다.
- 아무것도 저장하거나 보내지 않습니다.
